# 当前状态快照与 CAN 历史数据

Status: accepted

`gcan-api` 第一阶段将当前车辆 CAN 状态定义为实时快照，只表达系统当前看到的最新状态，允许被新 CAN 帧覆盖。GCAN 盒子的在线状态按最近一次原始 CAN 帧接收时间判断，第一阶段阈值配置为 10 秒；过期帧不用于刷新车辆 CAN 状态，也不写入 CAN 历史数据。需要追溯和查询的 CAN 数据作为 CAN 历史数据单独保留，并以 MySQL 中的原始 CAN 帧记录为准，不以内存 `Map + List` 作为历史存储，也不在第一阶段存解析后的历史状态；测试或联调场景可通过配置开关关闭历史写入。历史写入采用定时批量扫描实时快照的方式，默认 3 秒一次，并按 `GCAN 盒子 + CAN ID` 维护已写入水位避免重复写同一帧；第一阶段继续支持按 CAN ID 配置过滤，列表非空时只写指定 CAN ID，列表为空时写全部 CAN ID。
