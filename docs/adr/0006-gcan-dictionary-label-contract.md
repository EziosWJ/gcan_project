# gcan-api 通过字典契约获取展示名称

开放 API 需要同时返回煤矿、车型和状态的稳定编码与展示名称；`system-api` 继续作为字典名称的唯一来源，`gcan-api` 通过显式只读字典契约获取并缓存名称，不直接依赖 `system-api` 的实现代码或字典表。字典服务不可用时，`gcan-api` 至少返回稳定编码，名称回退为编码，保证监控数据仍可读取。

`gcan-api` 在启动时加载字典名称，并每 60 秒后台刷新；遇到未知编码时立即尝试刷新。刷新失败沿用旧缓存，无缓存时回退为编码，且字典刷新不阻塞车辆实时数据接口。

字典契约仅匿名开放 GCAN 监控所需的煤矿、车型、车辆连接状态和车辆解析状态，不扩展到系统用户、角色、菜单等其他系统字典。
